Hybrid architecture :
The idea is simple — do local aggregation first, then global attention:

Input [N, d_model]
      │
      ▼
GNN Layer (local message passing over neighbors)
      │                    ← captures local structure
      ▼
Graph Transformer Layer (global attention)
      │                    ← captures long range dependencies
      ▼
Classifier

Each GNN layer before the Transformer gives the model pre-aggregated neighborhood information 
— so global attention operates on richer node representations rather than raw features.

Approach 2— GCN + GT Hybrid          ← simplest
  GCN layers → GT layers

GCN -> Adding self loops -> Normalize -> Aggregation & Transformation

Key finding:
  Global attention alone → 60%
  Local (GCN) + Global (GT) → 79.20%

  The 20% gap empirically proves that
  local inductive bias is essential before
  global attention on small graphs like Cora.

Note :
Pure GCN is perfectly designed for Cora:
  - 2 layers = exactly 2-hop neighborhood
  - Direct classification from aggregated features
  - No redundant transformations
  - Minimal parameters = less overfitting on 140 nodes

Our Hybrid has extra complexity:
  - Input projection (extra transformation)
  - GT layers after GCN (extra parameters to overfit)
  - More total parameters trained on same 140 nodes
